# Intel Arc Pro B65: raw data

The measurements behind https://b65.thekaiser.us: four Intel Arc Pro B65 cards on one bare-metal host,
serving Qwen3.8-27B and other models with vLLM and llama.cpp. Everything here is plain CSV.

| Folder | What it holds |
| --- | --- |
| [`results/`](results/) | Every measured value: one row per metric of every test configuration, with its aggregation, repetitions and status |
| [`telemetry/`](telemetry/) | GPU and host sensor readings sampled during each run: temperatures, power, fan speed, clocks, utilisation, memory |

Start with [`results/headline-numbers.csv`](results/headline-numbers.csv): every number the website prints, with its model,
engine, cards and workload. Read [`report.md`](report.md) for the rig, the method and the limits.

Points columns: `campaign_id`, `cell_id` (join to `cells.csv`), `metric`, `aggregation` (mean, median, p95, mean of per-repetition p95s, sum...),
`rep` (`all` for an aggregate, else the repetition number), `n`, `value`, `value_text`, `unit`, `status`
(`measured`, `derived` = calculated from measured values, or a reason it is missing), `notes`.
A value that was not measured is an empty cell with a status, never a zero.

## Telemetry

Three files per run, sampled about every 5 seconds (xpu-smi about every second). `t_s` is seconds since the first sample of the file.

| File suffix | Columns |
| --- | --- |
| `-gpu.csv` | `t_s`, `card` (0-3), `gpu_busy_pct`, `package_temp_c`, `vram_temp_c`, `vram_hottest_channel_c`, `memory_controller_temp_c`, `pcie_temp_c`, `fan_rpm`, `power_w` (GPU-reported), `energy_counter_uj` (cumulative energy counter, microjoules) |
| `-xpusmi.csv` | `t_s`, `card`, `power_w`, `gpu_clock_mhz`, `throttle_reason` (`PowerBurst` = at the 200 W power limit), `vram_used_mib` |
| `-host.csv` | `t_s`, `cpu_busy_pct`, `cpu_temp_c`, `ram_used_gib`, `ram_available_gib`, `load_1min` |

Power is what the GPUs report; there was no wall meter and no ambient temperature sensor. A run covers the whole
benchmark invocation, including warm-up requests and pauses between concurrency levels.
